Key bullets (short, clear):

What it does (auto mimic trades in Involio using Notifications + Wallet tabs).

High‑level install steps:

Install Tampermonkey for Chrome (from Chrome Web Store).

Create a new userscript, paste the JS from Invoapp-Auto-Mimic-Trader-19.0-3.js.

Open two Chrome windows: app.invoapp.com/notifications and app.invoapp.com/wallet.
